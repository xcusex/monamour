# xcuse — Creative Portfolio

An editorial, single-page portfolio for a digital designer. The site combines an animated introduction, project concepts, an about section, a consultation call to action, and an FAQ.

## Preview

Open `index.html` in a browser, or run `start-site.bat` on Windows with Python 3 installed. The launcher starts a local preview on `127.0.0.1` and opens it in your browser. The page also loads Google Fonts and several background videos from the internet.

## Built with

- HTML, CSS, and vanilla JavaScript
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Google Fonts for Cormorant Garamond, Bodoni Moda, Manrope, and Golos Text

There is no package manager or build step.

## What's included

- Responsive one-page portfolio layout
- Animated hero, project cards, FAQ, and contact links
- Local images and a hero video in `assets/`
- `start-site.bat` for a simple local preview on Windows

The portfolio's contact buttons open Telegram. Project links lead to external demos. The site does not include a backend, contact form, analytics, or account system.
